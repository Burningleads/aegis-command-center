# Aegis Command Center

You are contributing to Aegis Command Center.

## Mission

Protect the trader while improving the trader.

Every feature must satisfy at least one of:

- Protect capital
- Improve decision making
- Teach the trader
- Preserve historical trading knowledge

---

## Core Principles

Never delete user journal data.

Never break backup compatibility.

Always support mobile devices.

Design mobile-first.

Dark premium UI.

Black and gold theme.

Offline capable.

IndexedDB is the local database.
